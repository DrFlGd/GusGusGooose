The first desktop release of Gus Gus Goose: fit magnet-mounted accessories to the desk goose, dress it, paint it and export 3MF for the slicer, now with a library of saved builds.

**Portable, no installer.** Download the file for your system, unzip it where you want the app to live, and run it. Saved builds go in `Gus Gus Goose Library` next to the app. Settings (the gear at the top right) can move the library to another folder, with or without its builds, or put it back next to the app.

- **Windows:** `…-windows-portable.zip`. SmartScreen will warn that the app is unrecognised because it isn't signed. Click *More info*, then *Run anyway*.
- **Linux:** `…-linux-x86_64.AppImage`. Run `chmod +x` on it, then start it.

**Library:** the Library tab keeps each build's model, settings, fitted part and paint. Builds are filed under holidays and categories, and have thumbnails, tags and descriptions. Open a build in the editor to keep working on it.
